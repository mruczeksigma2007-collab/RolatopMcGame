# RolatopMcGame
Wioska w stylu Minecrafta w 3D! Pomagaj mieszkańcom w zadaniach, zbieraj diamenty i awansuj na ścieżkach pomocy. Kupuj domy, urządzaj wnętrza i wynajmuj je. Otwieraj skrzynki z miksturami, zdobywaj nagrody w Battle Passie i walcz o miejsce w topce graczy. Uważaj: offline czynsz to tylko 10%!
